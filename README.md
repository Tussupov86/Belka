# Белка онлайн

Карточная игра Белка на четверых: открытый сайт, регистрация в самой игре (логин и пароль), столы, приватные столы по коду, боты, 20 секунд на ход, очки и уровни, рейтинг, админ-панель.

Сервер написан на чистом Node.js: внешних пакетов нет, устанавливать ничего не нужно.

## Запуск у себя на компьютере

Нужен Node.js версии 18 или новее.

```
ADMIN_PASSWORD=ваш_пароль_админа node server.js
```

Откройте http://localhost:3000.

## Настройки (переменные окружения)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PORT` | порт сайта | `3000` |
| `ADMIN_PASSWORD` | пароль администратора. Без него админ-панель выключена | — |
| `ADMIN_LOGIN` | логин администратора | `belka` |
| `DATA_DIR` | папка, где хранятся игроки (`db.json`) | `./data` |
| `IP_LOOKUP` | `off` — не спрашивать ip-api.com, мобильный ли адрес (бесплатный тариф ip-api — только для некоммерческого использования) | `on` |

Пароль админа задаётся только через переменную окружения и в коде не хранится. При каждом запуске сервер обновляет пароль админа по этой переменной.

## Как выложить в интернет

Сайту нужен хостинг, где работает Node.js и есть **постоянный диск** для папки `data`, иначе игроки пропадут при перезапуске.

Подходят:

- **VPS** (любой, например с Ubuntu): скопировать папку, запустить `node server.js` через `pm2` или `systemd`, поставить перед ним nginx с HTTPS.
- **Render.com**: новый Web Service из репозитория, команда запуска `node server.js`, добавить Disk (например, путь `/data`) и переменные `DATA_DIR=/data`, `ADMIN_PASSWORD=...`.
- **Railway / Fly.io**: так же, через Volume, смонтированный в `DATA_DIR`.
- В папке есть `Dockerfile` для хостингов, которые запускают контейнеры.

Бесплатные тарифы без диска тоже запустят игру, но регистрации будут стираться при каждом перезапуске.

## Статистика

Откройте `https://ваш-сайт/admin` (или `/stats`) и войдите логином и паролем админа. Там четыре вкладки:

- **Статистика** — сколько игроков зарегистрировано, онлайн, играет, график онлайна; обновляется каждые 5 секунд.
- **Игроки** — поиск, изменить очки, бан на час, снять бан и жалобы, задать новый пароль, удалить игрока. Пароли никто не видит: хранится только необратимый хеш.
- **Столы** — все открытые столы и партии, можно закрыть любой.
- **Объявление** — сообщение всем, кто сейчас онлайн.

Отдельная программа-монитор (`belka-monitor.zip`) показывает ту же статистику в своём окне.

## Что где

- `server.js` — сервер: регистрация, вход, столы, таймеры, очки, админ-панель.
- `engine.js` — правила Белки и бот.
- `public/index.html` — весь интерфейс.
- `public/cards/` — колода «Белка: Степь» (карты 6–A четырёх мастей и рубашка).

## Правила сервера

- Пароли хранятся только в виде хеша (scrypt). Их не видит никто, включая админа. Админ может задать игроку новый пароль.
- Карты соперников не уходят в браузер: каждый игрок получает только свою руку.
- Стол закрывается, когда за ним не остаётся живых игроков (пусто или одни боты). Отключившийся игрок до начала партии освобождает место через минуту.
- Очки: победа +10, победа в партии с яйцами +15, победа голой +25, поражение 0, ушёл или пропустил 3 хода подряд −5. Уровень — каждые 100 очков.
- Значок «IP» у ника: игроки за одним столом сидят в одной Wi-Fi сети (одинаковый внешний адрес и это не мобильный интернет). Мобильный интернет определяется по типу сети из браузера (Chrome на Android) и по справочнику ip-api.com (поле `mobile`). Сам адрес не показывается. Адрес берётся из `X-Forwarded-For` (его ставит хостинг или nginx).
- Столы и незаконченные партии сохраняются в `data/rooms.json`: после перезапуска сервера игра продолжится с того же места.
